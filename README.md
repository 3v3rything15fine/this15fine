This is a ready-to-upload zip containing a static Reveal.js web deck. It includes two parts:
- Part 1: The core workshop slides converted into Reveal sections
- Part 2: Operations Calendar MVP with a local-submission form and CSV export

How to deploy:
1) Zip the web/ folder
2) Upload to this15fine.dev, place at the desired root directory
3) Ensure static hosting serves index.html at the root
4) Open in a browser to test

Note: Submissions are stored in localStorage for MVP. Backend integration and real server-side submission/export would be a later enhancement.
